# Capy Mascot

A macOS Electron desktop mascot that reflects the development bridge, supports voice chat, and renders a Blender-exported 3D capybara.

## Run Locally

```bash
npm install
npm start
```

The development app loads credentials from `.env` when present. Never commit `.env` or copy secret values into source files.

## Voice Architecture

The voice conversation has two independent audio paths:

### Speech to Text

IBM Watson Speech to Text uses a WebSocket connection in `src/stt.js`:

1. The app opens a streaming recognition session.
2. Microphone chunks are sent as they are recorded.
3. Interim transcripts are shown in the mascot caption.
4. Watson closes the session after the stop action or inactivity timeout.

Required variables:

```dotenv
WATSON_STT_APIKEY=...
WATSON_STT_URL=...
WATSON_STT_MODEL=en-US_Multimedia
```

### Text to Speech

IBM Watson Text to Speech uses its WebSocket `/v1/synthesize` interface in `src/voice.js`:

1. The full response text is sent to Watson.
2. Watson returns binary MP3 chunks over the socket.
3. The app records first-chunk and total synthesis latency.
4. The collected MP3 is written to a temporary file and played by macOS `afplay`.

If the WebSocket request fails, the app falls back to the REST `POST /v1/synthesize` request before falling back to macOS `say`.

Required variables:

```dotenv
WATSON_TTS_APIKEY=...
WATSON_TTS_URL=...
WATSON_TTS_VOICE=en-US_MichaelExpressive
```

The app uses WebSockets for both STT and TTS. Playback still begins after the complete MP3 is collected because macOS `afplay` requires a file, but the transport now exposes first-chunk latency and has a REST fallback.

## Response Metrics

Voice turns log structured metrics from `src/main.js`:

```text
[metrics] stt.ready_ms=...
[metrics] chat_ms=...
[metrics] tts.websocket_first_chunk_ms=... tts.websocket_synthesis_ms=...
[metrics] tts_ms=... turn=... total_ms=... stt_ms=...
```

A recent development run showed:

- Chat generation: approximately 2.3 to 21.6 seconds
- TTS playback: approximately 10.0 to 19.9 seconds

TTS was the dominant measured delay in that run.

## Conversation Boundaries

Voice chat automatically stops after three completed turns. It also ends earlier when silence or Watson's inactivity timeout closes the session. Press the configured global shortcut to begin another conversation.

## macOS App

Build an unpacked arm64 `.app`:

```bash
npm run package:mac
```

Build distributable macOS artifacts:

```bash
npm run dist:mac
```

The installed development build is intended for Apple Silicon Macs. The packaged app stores user settings and the local environment in the user's application support directory rather than bundling secrets into the app.

## Settings

Settings are opened from the menu-bar tray icon. They include:

- Voice mode and IBM Watson voice selection
- Avatar X/Y/Z camera-axis offsets
- Outfit, default mood, and working helmet
- Always-on-top and launch-at-login behavior
- Saved mascot window position
- Microphone permission testing

The 3D capybara is generated by `tools/create_capybara.py` and exported to `assets/capybara.glb`.
